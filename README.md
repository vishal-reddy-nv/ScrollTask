# ScrollTask

Turn doomscrolling into progress.

Features:
- AI-generated micro tasks
- Goal tracking
- Social media interruption
- PDF task generation

## Installation

1. Download ZIP
2. Open Chrome
3. Go to:

chrome://extensions/

4. Enable Developer Mode
5. Click "Load unpacked"
6. Select ScrollTask folder
7. Click Configure API
8. Press the link to create free API key
9. Give some name and copy API key
10. Go back to "Goal" and give input 
Done.
